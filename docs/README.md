## What this repository contains, and what it deliberately keeps

MaxManager is **proprietary software** (see [LICENSE](../LICENSE)): it is not an open-source project and
this repository is not a contribution surface. What it is, is the project's public face plus its
engineering record.

| Layer | Where | Audience |
| --- | --- | --- |
| Product story and documentation | `README.md` · `README.ar.md` · `docs/` | Everyone |
| Screenshots | `docs/screenshots/` | Everyone |
| Visual assets for the docs | `docs/assets/` | Everyone (generated by `tools/gen_readme_assets.py`: the diagrams, the banners, and the contextual icons) |
| Provenance and licence measurement | `docs/PROVENANCE.md` · `docs/AUTHENTICITY.md` · `THIRD_PARTY_NOTICES.md` | Anyone checking licensing |
| The app, the daemons, the installer | `manager/` · `archdaemon/` · `thermalcore/` · `binprofiles/` · `binutils/` · `preloadbin/` · `mainfiles/` · `android/` | The project itself |
| Engineering record | `docs/ai/` · `docs/aegis/` | The project's own maintainers |
| Measurement tools | `tools/` | Anyone who wants to re-derive a claim |

**A note on the engineering record.** `docs/ai/` is the project's own working log: decisions (53 ADRs),
task handoffs, a validation contract and a review protocol. It is kept public on purpose — it is the
honest record of how the software was built, including the parts that failed. It is written in Arabic
because that is the language the maintainer works in; it is not a user manual and it is not translated.

**No secrets live here.** No keystore, no signing password, no API key, no device identifier. Release
signing fails fast when its password is absent rather than falling back to an unsigned build.

## Repository at a glance

| Path | What it holds |
| --- | --- |
| `manager/` | The Android application: the Compose UI, the arbiter, Atlas, Max AI, and the Rust JNI crate |
| `archdaemon/` | The C device service (14 components) and the Java companion (`nd.max.AppMonitor`) |
| `thermalcore/` · `binprofiles/` · `binutils/` · `preloadbin/` | The native daemons, one concern each |
| `mainfiles/` | The installer and boot scripts of the systemless module |
| `android/` | The ROM integration kit (`aosp/`, `kernelsu/`, `overlay/`) |
| `fixtures/contracts/` | The shared formats, measured from both sides — the cross-language contract |
| `tools/` | The gates and measurement tools that check every claim here |
| `docs/` | This documentation, plus the project's engineering record |
| `docs/assets/` · `docs/screenshots/` | Generated visual assets — banners, diagrams and the section icons — plus the screenshot contract |
